# 權威加權準則 v0.1

攝影論述沒有引用資料庫,無法用引用次數判斷權威。本專案改用三個可查證訊號,
刻意保持可解釋、可被審查,不做黑箱。

## 一、來源分級(tier)與基礎權重

| tier | 定義 | 基礎權重 |
|---|---|---|
| primary | 原典:思想家本人的著作、原始攝影集 | 0.85 |
| institution | 館所與學院:MoMA、George Eastman、學院出版社、正典展覽 | 0.75 |
| critic | 學術評論與選集:期刊、理論選集、專書評論 | 0.60 |
| other | 其他:部落格、一般媒體、二手整理 | 0.40 |

## 二、佐證數(corroboration)

同一條關係若有多個獨立來源支持,每多一個 +0.10(上限封頂於 1.0 前)。

## 三、直接程度(directness)

關係在來源中被陳述的明確程度,作為乘數:

- 1.0 文中明說(例:伯格《觀看的方式》開宗明義改寫班雅明)
- 0.7 隱含但合理
- 0.5 需要詮釋或僅二手並置(例:巴特此曾在與班雅明靈光的共鳴)

## 四、公式與分流

```
confidence = min(1.0, tier_base + 0.10 * (n_sources - 1)) * directness
```

- confidence ≥ 0.70 → 自動入圖(status = auto)
- confidence < 0.70 → 進人工佇列(status = review),由人工抽查
